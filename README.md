# Jukebox for Windows

Downloads and updates for Jukebox, a personal music jukebox: it plays the music folder on your PC, gapless, with playlists, smart playlists, an equalizer, a visualizer and listening stats, and lets a phone or tablet on the same Wi-Fi play it or remote-control the PC.

**To install:** open the latest release, download `Jukebox-<version>-Windows.zip`, extract it and run `Jukebox.exe` (see README.txt inside). An installed Jukebox updates itself.

The other files in each release (`jukebox-app-*.zip`, `update.json`) are what installed copies download to update; you do not need them.
